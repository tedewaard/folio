# Building with SvelteKit

SvelteKit is an amazing framework for building modern web applications. Here's why I love it:

## Why SvelteKit?

1. **Performance** - Svelte compiles your code to efficient vanilla JavaScript
2. **Developer Experience** - Simple, intuitive API with minimal boilerplate
3. **File-based Routing** - Just create files in the routes directory
4. **Server-Side Rendering** - Built-in SSR and SSG support

## Adding Markdown Support

With mdsvex, you can write your blog posts in Markdown and have them rendered as Svelte components. It's the best of both worlds!

```javascript
// Example code block
const greeting = 'Hello, world!';
console.log(greeting);
```

This makes content creation a breeze while maintaining full control over styling and interactivity.
